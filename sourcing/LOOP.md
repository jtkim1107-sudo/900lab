# 소싱 루프 (루프 ⑦) — 실행 스펙

> 목적: **전 세계 시장을 조사해 "탈탈팩토리에서 팔면 가장 효과가 좋을 제품"을 매주 발굴한다.**
> 우리 창고 재고에서 고르는 게 아니다. 바깥에서 찾아온다.
> 이 문서는 매주 자동 실행되는 세션의 작업 지침이다.

## 실행 주기

- 매주 월요일 오전 (Routine 자동 실행, 새 세션)
- 산출물: `sourcing/reports/YYYY-Www.md` + 커밋/푸시
- 실행 후 관리자에게 요약 보고 → **승인된 후보만** 다음 단계(샘플 발주)로

## 1단계 — 조사 (매주 최소 4개 소스 계열)

| 소스 계열 | 보는 것 |
|---|---|
| 바이럴/SNS | TikTok viral products, 릴스·쇼츠에서 도는 생활템 |
| 드랍쉬핑 위닝 리스트 | 주방·청소·수납 카테고리의 winning products (마진·수요 검증됨) |
| 균일가샵 히트 | 다이소·세리아·3COINS 신상 히트템 (한국 소비자 검증) |
| C커머스 한국 베스트 | 알리·테무 한국 판매량 상위 생활용품 (수요+공급가 동시 확인) |
| 시즌 캘린더 | 4~8주 뒤 시즌 수요 (장마→제습, 겨울→방한 등) |

## 2단계 — 스코어링 (100점)

| 축 | 배점 | 기준 |
|---|---|---|
| 반복구매성 | 25 | 소모품인가, 재구매 주기가 있는가 |
| 배송 경제성 | 20 | 경량(500g↓)·저부피인가. 택배비를 이기는가 |
| 균일가 적합 | 20 | 도매가 기준 4단(900~4,900) 안에서 마진이 남는가 (목표 원가율 35%↓) |
| 트렌드 모멘텀 | 15 | 지금 뜨는 중인가 (정점 지난 것 감점) |
| 영상 데모성 | 10 | 15초 영상으로 "오!" 가 나오는가 (마케팅 루프 연료) |
| 공급 접근성 | 10 | 이우·알리바바 등에서 소량 테스트 발주 가능한가 |

**자동 탈락 조건**: KC 인증 필요 품목(전기·유아 입에 닿는 것 등)은 인증 계획 없으면 보류 /
크고 무거운 것 / 식품·화장품(수입 인허가) / 지재권 위험(캐릭터 카피 등)

## 3단계 — 산출물 형식

리포트에 반드시 포함:
1. 후보 테이블 (10~15개): 제품명 · 카테고리 · 추정 도매가 · 배정 가격관 · 점수 · 근거 출처
2. TOP 5 상세: 왜 우리 몰에서 터지는가, 소싱 경로, 리스크
3. 지난주 승인 후보의 진행 상태 (샘플 도착 → 테스트 입점 → 판매 데이터)
4. 퇴출 제안: 테스트 입점 후 N주간 판매 부진 SKU

## 4단계 — 승격 게이트 (사람이 하는 유일한 일)

```
후보 발굴(자동) → 관리자 승인 → 샘플 발주(수동) → 테스트 입점(소량)
→ 2주 판매 데이터 → 정번 승격 or 퇴출(자동 제안)
```

- 돈이 나가는 단계(발주)는 반드시 관리자 승인
- 승인/거부 이력은 리포트에 누적 → 루프가 관리자의 취향을 학습한다
