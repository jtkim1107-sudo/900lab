## 3. 디자인 시스템 (프로토타입에서 검증됨)

### 컬러 — 색이 곧 정보

| 토큰 | HEX | 용도 (이 용도 외 사용 금지) |
|---|---|---|
| Paper | `#F6F4EE` | 바탕 (따뜻한 종이색) |
| Ink | `#191713` | 텍스트·버튼·전광판 |
| Tag Yellow | `#FFD23F` | 브랜드 컬러. 가격 스티커·로고·혜택 |
| Punch Red | `#E5472D` | 품절임박·SOLD OUT·게이지 미달성 |
| Go Green | `#178A50` | 무료배송 달성·아낀 금액 |

보조: Line `#E3DFD4`, Muted `#7C766B`, Tag Deep `#E9B914`, Go Soft `#E3F2E9`

### 타이포

- **Pretendard** 단일 서체, 무게로만 위계 (Display 900 / Body 500 / Caption 700+자간)
- 숫자는 항상 `font-variant-numeric: tabular-nums`
- 큰 제목은 자간 -1px 내외로 타이트하게

### 시그니처 컴포넌트

1. **가격 스티커** — 펀칭 구멍 + 살짝 회전 + 하드섀도(2px offset). 티어별 색: 900 노랑 / 1,900 흰색 / 2,900 민트 / 4,900 빨강
2. **SOLD OUT 도장** — 이중 테두리, -10° 회전, multiply 블렌드
3. **재고 소진전 전광판** — 검정 바탕 + 노랑 줄무늬 게이지 (움직임)
4. **무료배송 게이지** — 빨강 줄무늬 채움 + 진행률 따라 달리는 🚚, 달성 시 초록
5. **하드섀도** — 강조 요소에만 `2~3px offset` 잉크색 그림자. 상품 카드는 라이트 스타일(얇은 라인 + 소프트 섀도)

### 무드 키워드

"창고에서 갓 붙인 가격표" — 스티커, 도장, 크라프트, 전광판. 촌스러운 폐업세일이 아니라 **잘 정리된 균일가 스토어**.
