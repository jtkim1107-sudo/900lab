# 카페24 이식 가이드

이 프로토타입(`index.html`)은 카페24 스킨으로 옮기는 것을 전제로 만든 시연용 페이지입니다.
데모 데이터(상품 24종, 재고, 주문)는 전부 브라우저 안에서만 동작하며 실제 결제는 없습니다.

## 프로토타입 → 카페24 매핑

| 프로토타입 영역 | 카페24 대응 |
|---|---|
| 상품 그리드 (`#grid`) | `product/list` 모듈 — 상품 진열, 남은 수량은 `품절임박 수량 표시` 설정 + 스킨 변수 |
| 900원관/1,900원관 필터 탭 | 상품분류 2개 생성 후 분류 링크로 대체 |
| 가격 스티커/균일가 | 상품 등록 시 판매가 2,900/4,900 고정 |
| 무료배송 게이지 (하단 고정바) | 스킨 커스텀 JS — 장바구니 합계 API(`EC_FRONT`) 값으로 동일 로직 이식 |
| 9,800원 이상 무료배송 | 쇼핑몰 설정 > 배송 정책 > 조건부 무료배송 (기본 기능) |
| 장바구니 드로어 | `order/basket` 커스텀 또는 기본 장바구니 페이지 사용 |
| 주문/결제 모달 | 카페24 기본 주문서 + PG(카페24페이먼츠/토스) — 프로토타입 모달은 폐기 |
| SOLD OUT 표시 | 품절 상품 진열 유지 설정 (기본 기능) |
| 전체 소진율 배너 | 스킨 커스텀 — 총 재고 대비 판매량은 관리자 API 또는 수동 갱신 |

## 카페24 세팅 순서

1. 카페24 가입 → 쇼핑몰 생성
2. 사업자등록 + 통신판매업 신고 번호 입력
3. PG 신청 (카페24페이먼츠 권장, 심사 2~5일)
4. 배송 정책: 기본 배송비 3,500원 / 9,800원 이상 무료
5. 상품분류: `2,900원관`, `4,900원관` 생성
6. 상품 일괄등록 (엑셀) — 리파코 재고 리스트를 카페24 양식으로 변환
7. 스킨 선택 후 이 프로토타입의 디자인 토큰(색/타이포)과 게이지 JS 이식
8. 테스트 주문 → 오픈
